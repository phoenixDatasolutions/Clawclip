# ClawClip

**Modular Multi-Agent AI Platform — Connect Any LLM, Any Messaging App**

ClawClip is a self-hosted, open-source AI agent platform that connects your favorite messaging apps to powerful AI models through a multi-agent orchestration engine. Like having a team of AI specialists working together on your tasks.

## Key Features

- **Any Messaging Platform** — Telegram, Discord, Slack, WhatsApp, Signal, Matrix, Web UI, CLI
- **Any LLM** — Claude, GPT, Gemini, Ollama (local), LiteLLM, any OpenAI-compatible API
- **Multi-Agent Orchestration** — Coordinator decomposes tasks and delegates to specialized agents (Code, Research, System, DevOps) that work in parallel
- **Plugin/Skill System** — 14+ built-in skills (shell, files, git, system monitor, screenshots, code review, CI/CD, and more)
- **MCP Protocol** — Bidirectional Model Context Protocol support
- **RAG Knowledge Base** — Index your docs and codebase for agent context
- **Workflow Engine** — YAML-defined automation pipelines with triggers
- **Web Dashboard** — Real-time control panel with feature toggles, analytics, and live agent status
- **Docker Sandboxing** — Isolated code execution environments
- **Conversation Branching** — Fork and merge conversations like git branches
- **Self-Healing Agents** — Auto-retry with strategy switching and failure escalation
- **One-Step Install** — Setup wizard guides non-tech users through configuration

## Quick Start

### Option 1: One-Line Install
```bash
git clone https://github.com/user/clawclip.git
cd clawclip
./setup.sh
```

### Option 2: Manual Install
```bash
git clone https://github.com/user/clawclip.git
cd clawclip
python -m venv .venv
.venv/Scripts/pip install -e ".[all]"   # Windows
# .venv/bin/pip install -e ".[all]"     # Linux/Mac
clawclip setup    # Interactive wizard
clawclip run      # Start
```

### Option 3: Docker
```bash
git clone https://github.com/user/clawclip.git
cd clawclip
cp .env.example .env   # Fill in your API keys
docker compose up -d
```

## Install Options

```bash
pip install -e ".[minimal]"     # Telegram + Claude + Dashboard
pip install -e ".[all]"         # Everything
pip install -e ".[telegram,claude-api,dashboard]"  # Pick and choose
```

## Architecture

```
User Message (Telegram/Discord/Slack/...)
    ↓
Platform Adapter → EventBus → Message Router
    ↓
Coordinator Agent (analyzes & decomposes task)
    ↓
Specialized Agents (parallel execution)
├── Code Agent      → Shell, Files, Git skills
├── Research Agent   → Web Search, Knowledge Base
├── System Agent     → Monitor, Screenshot, Services
└── DevOps Agent     → CI/CD, Deployment
    ↓
Results → Coordinator → Response → Platform Adapter → User
```

## Project Structure

```
clawclip/
├── core/           # Types, events, interfaces, config, DI
├── platforms/      # Messaging adapters (Telegram, Discord, Slack, ...)
├── providers/      # LLM adapters (Claude, OpenAI, Gemini, Ollama, ...)
├── agents/         # Multi-agent orchestration engine
├── skills/         # Plugin system (shell, files, git, ...)
├── storage/        # SQLAlchemy models and repositories
├── security/       # Auth, RBAC, rate limiting, encryption
├── dashboard/      # Web UI control panel
├── workflows/      # YAML pipeline engine
├── knowledge/      # RAG knowledge base
├── scheduler/      # Cron-based task scheduling
├── webhooks/       # Webhook API gateway
├── mcp/            # Model Context Protocol
├── setup_wizard/   # Interactive CLI setup
└── system/         # Low-level system operations
```

## Configuration

ClawClip uses a two-file config system:
- `config/default.yaml` — Shipped defaults (never edit)
- `config/local.yaml` — Your overrides (auto-generated by setup wizard)

Every feature is toggleable via the Web Dashboard or YAML config.

## CLI Commands

```bash
clawclip run              # Start the platform
clawclip setup            # Run setup wizard
clawclip config check     # Validate configuration
clawclip config show      # Show current config
clawclip db migrate       # Run database migrations
clawclip skills list      # List available skills
clawclip agents list      # List available agents
```
